# SiteMark — Design

> Tokens: [`src/styles/tokens.css`](../src/styles/tokens.css) · Primitives: [`src/styles/base.css`](../src/styles/base.css) · Logo: [`design/logo/`](../design/logo)
> Revised after the [2026-09-25 plan review](reviews/2026-09-25-plan-review.md). Terminology: **site group** (D-202).

## 1. Principles

1. **Soft chrome, loud marks.** The extension UI is calm neumorphic grey. The marks on
   websites are loud, saturated and always carry text. The UI accent (coral) is deliberately
   a different hue from the red mark preset.
2. **Accessible soft UI.** Neumorphism alone fails WCAG. We always keep:
   - AA text contrast,
   - **3:1 control boundaries** (`--sm-control-border`),
   - an `outline` focus ring (it survives forced-colors mode),
   - state shown by more than shadow (color + label).
3. **Never color alone.** Marks have mandatory text, and the presets are colorblind-safe (D-205).
4. **Marks must not hurt the page.** No layout shift, input passes through, and ribbons and banners fade when the pointer is near.
5. **No network.** System fonts only, inline SVG icons, and nothing loaded from a CDN.

## 2. Brand

**Concept:** a coral **bookmark ribbon** (the _Mark_) on a raised soft tile (the _Site_), with a
**pointer cursor** (the picker) over the ribbon's notch.

**Rules:**

- Keep clear space of ¼ of the icon width.
- Use soft shadows only at ≥ 48 px.
- Don't recolor the ribbon, except in the mono variant.
- Store icons: 96 px art centered in 128 px (Chrome guideline). This is checked in T-152.

### Color: mark presets (D-205, colorblind-safe)

The presets are spread along the blue–yellow axis and in luminance, so they stay distinct under
protanopia, deuteranopia and tritanopia. They always come with text (REQ-MARK-015).

| Preset | Hex       | Auto text | Typical use                                |
| ------ | --------- | --------- | ------------------------------------------ |
| Red    | `#c93a2e` | white     | production                                 |
| Amber  | `#f4a300` | black     | acceptance / staging                       |
| Blue   | `#1f6feb` | white     | test (and "Mark this site" default, D-201) |
| Slate  | `#57606a` | white     | development / local                        |
| Custom | any hex   | auto      | anything else                              |

## 3. Elevation, shape, type

| Token            | Recipe                                 | Used for                                  |
| ---------------- | -------------------------------------- | ----------------------------------------- |
| `--sm-raised`    | 6/6/12 dark + −6/−6/12 light           | Cards                                     |
| `--sm-raised-sm` | 3/3/6 dark + −3/−3/6 light             | Buttons, chips, switch knob               |
| `--sm-inset`     | inset 3/3/6 dark + inset −3/−3/6 light | Inputs, wells, switch track, segmented bg |
| `--sm-pressed`   | inset 2/2/4                            | Active/pressed buttons, selected segment  |

Shadows are **decoration only**. Boundaries come from `--sm-control-border`, or from transparent borders
that become visible in forced-colors mode.

- **Radii:** 8 (chips, inputs), 12 (buttons, wells), 20 (cards), pill (switches).
- **Spacing:** 4 px grid (4/8/12/16/24/32).
- **Type:** system rounded stack at 12/14/16/20 px (28 px for the options title). **12 px minimum.** Weights 400/600/700.
- **Targets:** ≥ 24 × 24 px (popup buttons 32 px, options 36 px, swatches 28 px with 8 px gaps).

## 4. Components (`src/ui/components`, CSS Modules)

| Component  | Anatomy / behavior                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| Button     | raised-sm, pressed on `:active`. `primary` = accent fill. Icon + label                                                      |
| IconButton | 32 × 32 round, raised-sm, **must** have `aria-label`                                                                        |
| Switch     | Inset pill track with `--sm-control-border`, raised knob. On = accent track + knob right. `role="switch"`, visible label    |
| Card       | raised, radius 20, padding 16, `--sm-edge` highlight                                                                        |
| Field      | Label above, inset input with a control border, helper/error below (`aria-describedby`). Error = warning/danger text + icon |
| Segmented  | Inset container with a border; the selected segment is raised-sm (radio group)                                              |
| Slider     | Inset track, raised thumb, value bubble, keyboard steps                                                                     |
| ColorField | 4 preset swatches (28 px, check mark when selected, `forced-color-adjust: none` + border), custom hex, native picker        |
| Dialog     | Raised card over a 40 % scrim, focus trapped, Esc closes                                                                    |
| Toast      | Bottom center, raised, auto-dismiss after 4 s (paused on hover/focus), action button (Undo)                                 |
| ColorChip  | 12 px circle in the mark color with a 1 px control-border ring                                                              |

### 4a. States matrix (each component must define all of these)

| State    | Light / dark                                   | Forced colors                           |
| -------- | ---------------------------------------------- | --------------------------------------- |
| Default  | Surface + raised/inset + control border        | `ButtonText` border                     |
| Hover    | Slightly stronger shadow                       | unchanged                               |
| Focus    | 2 px `outline` in `--sm-focus-color`, offset 2 | `Highlight` outline                     |
| Pressed  | `--sm-pressed`                                 | `Highlight` border                      |
| Selected | Accent fill or raised segment + check icon     | `Highlight` background, `HighlightText` |
| Disabled | 50 % opacity, `aria-disabled`                  | `GrayText`                              |
| Error    | Warning/danger text + icon + border            | `ButtonText` + icon                     |

```text
│ │ ○ Payments admin  Disabled — enable in settings ↗ │
│ ╰────────────────────────────────────╯ │
│ [ ⌖ Pick element ]                     │  ← actions stacked full width
│ [ 👁 Hide on this tab ]  (⌨ if set)    │  ← toggle; pressed when hidden; no default key (D-208)
│ Alt+Shift+M to pick                    │  ← live binding from commands.getAll()
└────────────────────────────────────────┘
```

**B. No match:** an inset well with "No site group matches this site", a primary **Mark this site**
button (with microcopy underneath: _"Your browser will ask to let SiteMark show marks on this site."_)
and a secondary "Pick element".
**C. Not granted:** a warning card, "SiteMark needs access to app.example.com to show your marks on
every visit", with **Allow**.
**D. Can't run here:** "SiteMark can't run on this page", with actions disabled.
**E. Read-only / corrupt data:** a danger card linking to settings.
**Toolbar badge:** "!" in `--sm-warning` on a tab with a render problem (D-219).

### 5.3 Picker

- **Glass pane** over the viewport (invisible). The hovered element gets a **neutral two-tone dashed outline**
  (2 px white + 2 px `#1b1d22`, readable on any background) and a raised tooltip pill:
  `button#delete.btn-danger · 120×36`. Inside iframes it says "marks the whole frame"; inside components,
  "marks the component".
- **Hint bar** (compact, top center; moves to the bottom when the pointer is within 80 px):
  "Click to select · ↑↓←→ navigate · Enter select · Esc cancel".
- **Mini panel** after selection (~320 px, auto-placed on the side **opposite** the selection, with a **Move panel**
  button that cycles corners):

## 6. Marker effects (injected, REQ-MARK-*)

Everything lives inside `<sitemark-root>`'s shadow root, with `pointer-events: none` and `forced-color-adjust: none`.
Frames, outlines, ribbons and banners get a 1 px keyline in the auto text color at 60 % (REQ-RND-014).
Ribbons and banners fade to 15 % when the pointer is within 24 px (REQ-RND-013).

| Effect        | Spec                                                                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ribbon (page) | A 180 × 32 px band rotated 45° across the corner. Bold uppercase, 12 px shrinking to 9 px to fit ≤ 16 chars, letter-spacing .06em, subtle shadow                                     |
| Ribbon (elem) | Band height clamp(16 px, 12 % of the element's short side, 28 px), clipped to the element's box. Short side < 80 px → 10 px corner dot                                               |
| Banner        | Compact 24 px / regular 36 px, one per edge (merged `A · B`), a small SiteMark glyph on the left, a focusable chevron on the right that collapses it to a 24 × 24 tab. `role="note"` |
| Frame         | Borders on four fixed edge strips (not box-shadow, so forced colors don't remove it). Multiple frames nest                                                                           |
| Outline       | Overlay box at the target rect + 2 px, W px style. Pulse is a 1.6 s glow (off with reduced motion)                                                                                   |
| Tint          | Color overlay: page 3–15 %, element 5–40 %                                                                                                                                           |
| Stripes       | `repeating-linear-gradient(-45deg, color 0 12px, transparent 12px 24px)`. `edge` = a 6 px strip at the top of the viewport; `full` = the whole area                                  |
| Watermark     | Tiled SVG of the rotated (−30°) text, 20 px bold, at 4–12 %                                                                                                                          |
| Title prefix  | `trim(prefix) + ' ' + title`, idempotent, re-applied at most 4 times per second, stripped on removal                                                                                 |
| Favicon       | The original drawn on a 32 px canvas + a 12 px dot in the mark color with a 2 px white ring. If unreadable → unchanged + status "unavailable"                                        |

## 7. Motion

The default is 160 ms `cubic-bezier(.2,.8,.2,1)` for press and hover. Toasts and drawers slide 8 px and fade in. The proximity fade takes 120 ms.
Everything becomes 0 ms under `prefers-reduced-motion`.

## 8. Theming

`tokens.css` puts the light values on `:root`, the dark values under `prefers-color-scheme: dark` (unless
`data-theme="light"`), and forces dark with `data-theme="dark"`. The popup, options page and picker panel set `data-theme` from
settings (REQ-THEME-001). A `forced-colors: active` block maps boundaries, states and focus to system colors
(REQ-A11Y-007). Marks don't follow the theme: they use the user's mark colors.
