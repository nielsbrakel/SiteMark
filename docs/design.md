# SiteMark — Design

> Tokens: [`src/styles/tokens.css`](../src/styles/tokens.css) · Primitives: [`src/styles/base.css`](../src/styles/base.css) · Logo: [`design/logo/`](../design/logo)
> Revised after the [2026-09-25 plan review](reviews/2026-09-25-plan-review.md). Terminology: **site group** (D-202).

## 1. Principles

1. **Paper chrome, loud marks.** The extension UI is warm paper on a kraft board (D-289). The marks on
   websites are loud, saturated and always carry text. The UI accent (coral) is deliberately
   a different hue from the red mark preset.
2. **Decoration never carries meaning.** Tape, pins, tilt and paper shadows are decoration. We always keep:
   - AA text contrast,
   - **3:1 control boundaries** (the ink outline, `--sm-control-border`),
   - an `outline` focus ring (it survives forced-colors mode),
   - state shown by more than color or shadow (color + label).
3. **Never color alone.** Marks have mandatory text, and the presets are colorblind-safe (D-205).
4. **Marks must not hurt the page.** No layout shift, input passes through, and ribbons and banners fade when the pointer is near.
5. **No network.** Local fonts only (Caveat Brush and Patrick Hand ship in the extension, D-289), inline SVG icons, and nothing loaded from a CDN.

**Concept:** a coral **bookmark ribbon** (the _Mark_) cut from paper and taped onto a note (the _Site_), with a
**pointer cursor** (the picker) over the ribbon's notch. The wordmark is hand-lettered: "Site" in ink, "Mark" in coral on a highlighter stroke.

**Rules:**

- Keep clear space of ¼ of the icon width.
- Don't recolor the ribbon, except in the mono variant.
- Store icons: 96 px art centered in 128 px (Chrome guideline). This is checked in T-152.

### Color: mark presets (D-205, colorblind-safe)

The presets are spread along the blue–yellow axis and in luminance, so they stay distinct under

| Slate  | `#57606a` | white     | development / local                        |
| Custom | any hex   | auto      | anything else                              |

## 3. Elevation, shape, type

| Token          | Recipe                                                 | Used for                                   |
| -------------- | ------------------------------------------------------ | ------------------------------------------ |
| `--sm-lift`    | 1/2/2 + 0/10/16 shade, plus the `--sm-paper-edge` line | Sheets (cards, dialogs, the popup)         |
| `--sm-lift-sm` | 1/3/0 `--sm-text` (hard ink)                           | Buttons, chips, switch knob                |
| `--sm-well`    | none (paper has no sunken wells)                       | Inputs, switch track, segmented background |
| `--sm-pressed` | the control moves 3 px down, no shadow                 | Active/pressed buttons                     |

Shadows, tape and tilt are **decoration only**. Boundaries come from `--sm-control-border`, or from transparent borders
that become visible in forced-colors mode. Tilt (±2°) applies to titles and cards, not to popup controls, and is off under reduced motion.

- **Radii:** 3 (sheets, buttons, inputs, chips), pill (switches, swatches).
- **Spacing:** 4 px grid (4/8/12/16/24/32).
- **Type:** Patrick Hand for text at 16/18/20/22 px (body 18 px) and Caveat Brush for titles at 24 px and up (D-289), both bundled locally with a system fallback. **15 px minimum** (handwriting has a small x-height). One weight each.
- **Targets:** ≥ 24 × 24 px (popup buttons 32 px, options 36 px, swatches 28 px with 8 px gaps).

## 4. Components (`src/ui/components`, CSS Modules)

| Component  | Anatomy / behavior                                                                                                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Button     | Ink outline, `--sm-lift-sm`; pressed moves down 3 px on `:active`. `primary` = accent fill. Icon + label                                                                                                           |
| IconButton | 32 × 32 round, outlined, **must** have `aria-label`                                                                                                                                                                |
| Switch     | 78 × 34 pill track with an ink outline, solid ink 22 px thumb. On = sage track + knob right, with the words On / Off inside the track. `role="switch"`, visible label ("Ingeschakeld" / "Enabled")                 |
| Card       | A paper sheet: `--sm-surface`, outline, `--sm-lift`, radius 3, padding 16. Optional **striped** tape strip on top (`.sm-tape`: `--sm-tape-stripes` over a `--sm-tape-*` fill; decorative, hidden in forced colors) |
| Field      | Label above, `--sm-surface-2` input with an ink outline, helper/error below (`aria-describedby`). Error = warning/danger text + icon                                                                               |
| Segmented  | Outlined container divided by ink lines; the selected segment is paper with a coral marker line under it (radio group, D-296)                                                                                      |
| Slider     | Outlined track, round thumb, value bubble, keyboard steps                                                                                                                                                          |
| ColorField | 4 preset swatches (28 px, check mark when selected, `forced-color-adjust: none` + border), custom hex, native picker                                                                                               |
| Dialog     | A paper sheet over a 40 % scrim, focus trapped, Esc closes                                                                                                                                                         |
| Toast      | Bottom center, a small sheet, auto-dismiss after 4 s (paused on hover/focus), action button (Undo)                                                                                                                 |
| ColorChip  | 12 px circle in the mark color with a 1 px control-border ring                                                                                                                                                     |

### 4a. States matrix (each component must define all of these)

| State    | Light / dark                                   | Forced colors                           |
| -------- | ---------------------------------------------- | --------------------------------------- |
| Default  | Sheet + control border + lift                  | `ButtonText` border                     |
| Hover    | 2 px lift (cards and titles also tilt 1.5°)    | unchanged                               |
| Focus    | 2 px `outline` in `--sm-focus-color`, offset 2 | `Highlight` outline                     |
| Pressed  | `--sm-pressed` (moves down, shadow gone)       | `Highlight` border                      |
| Selected | Selection mark, see 4b                         | `Highlight` background, `HighlightText` |
| Disabled | 50 % opacity, `aria-disabled`                  | `GrayText`                              |
| Error    | Warning/danger text + icon + border            | `ButtonText` + icon                     |

### 4b. Selection marks (D-296)

One hand-drawn mark per kind of control, always with bold text or an underline, never color alone:

| Control                           | Mark                                                     |
| --------------------------------- | -------------------------------------------------------- |
| Header link (`.sm-nav-link`)      | Wavy underline in the text color, through descenders     |
| Borderless list item (`.sm-pick`) | 2 px coral outline, 1° off true, bold text               |
| Segmented and language switch     | Paper segment with a 3 px coral marker line, tilted 1.2° |
| Switch                            | Green track, knob right, On / Off words inside the track |
| Inline help link (`HelpTip`)      | Wavy underline                                           |
| Button, color swatch              | Unchanged: pressed in with tape yellow, double ink ring  |

A new selectable control picks the row that matches: borderless gets `.sm-pick`, anything with its own border gets the marker line.

## 6. Marker effects (injected, REQ-MARK-*)

Everything lives inside `<sitemark-root>`'s shadow root, with `pointer-events: none` and `forced-color-adjust: none`.
Frames, outlines, ribbons and banners get a 1 px keyline in the auto text color at 60 % (REQ-RND-014).
Ribbons and banners fade to 15 % when the pointer is within 24 px (REQ-RND-013).

| Effect        | Spec                                                                                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ribbon (page) | A 180 × 32 px band rotated 45° across the corner. Bold uppercase, 12 px shrinking to 9 px to fit ≤ 16 chars, letter-spacing .06em, subtle shadow                                     |
| Ribbon (elem) | Band height clamp(16 px, 12 % of the element's short side, 28 px), clipped to the element's box. Short side < 80 px → 10 px corner dot                                               |
| Banner        | Compact 24 px / regular 36 px, one per edge (merged `A · B`), a small SiteMark glyph on the left, a focusable chevron on the right that collapses it to a 24 × 24 tab. `role="note"` |
| Frame         | Borders on four fixed edge strips (not box-shadow, so forced colors don't remove it). Multiple frames nest                                                                           |
| Outline       | Overlay box at the target rect + 2 px, W px style. Pulse is a 1.6 s glow (off with reduced motion)                                                                                   |
| Tint          | Color overlay: page 3–15 %, element 5–40 %                                                                                                                                           |
| Stripes       | `repeating-linear-gradient(-45deg, color 0 12px, transparent 12px 24px)`. `edge` = a 6 px strip at the top of the viewport; `full` = the whole area                                  |
| Watermark     | Tiled SVG of the rotated (−30°) text, 20 px bold, at 4–12 %                                                                                                                          |
| Title prefix  | `trim(prefix) + ' ' + title`, idempotent, re-applied at most 4 times per second, stripped on removal                                                                                 |
| Favicon       | The original drawn on a 32 px canvas + a 12 px dot in the mark color with a 2 px white ring. If unreadable → unchanged + status "unavailable"                                        |

## 7. Motion

The default is 160 ms `cubic-bezier(.2,.8,.2,1)` for press, hover and tilt. Toasts and drawers slide 8 px and fade in. The proximity fade takes 120 ms.
Everything becomes 0 ms under `prefers-reduced-motion`.

## 8. Theming

`tokens.css` puts the light values on `:root`, the dark values under `prefers-color-scheme: dark` (unless
`data-theme="light"`), and forces dark with `data-theme="dark"`. The popup, options page and picker panel set `data-theme` from
settings (REQ-THEME-001). A `forced-colors: active` block maps boundaries, states and focus to system colors
(REQ-A11Y-007): ink outlines become `ButtonText`, and tape, pins, tilt and shadows are removed. Marks don't follow the theme: they use the user's mark colors.
