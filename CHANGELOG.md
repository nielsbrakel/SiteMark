# SiteMark changelog

## Unreleased

- New hand-drawn marks for what is selected: a wavy underline under the current header link, a coral outline around the current site group and help topic, a marker line under the current switch segment, and On / Off words inside the switches.
- The popup and the settings page link to the website's help: a Help link in the header and short tips under URL patterns, marks, shortcuts and diagnostics. Keyboard shortcuts are shown as key caps.
- Website: the home page now shows a shop page without and with SiteMark's marks, with a slider to compare them.
- Inline code (URL patterns, flags, paths) is now drawn as a torn strip of green washi tape, on the website and in the extension.

## 1.1.1

- Same as 1.1.0; this version fixes the store publishing so Chrome, Firefox and Edge get the same release.

## 1.1.0

- New scrapbook look: kraft paper, handwriting type and a new logo in the extension and on the website.
- New "Midnight Plum" dark theme.
- The website's install button suggests the store for your browser.
- Safari is coming in the future, not in this release.

## 1.0.0

- First release for Chrome, Edge and Firefox.
- Mark the sites you choose with ribbons, banners, outlines, stripes, watermarks, a tab-title prefix or a favicon dot.
- Pick one element on a page and mark it, with an editable CSS selector.
- Private by design: no data collected, and access is requested one site at a time.
- English and Dutch.
