# SiteMark changelog

## Unreleased

## 1.3.0

- The toolbar icon now carries a small sticker: a green check where a site group is active, a grey dash where its marks are hidden or the group is switched off, and an amber exclamation mark when something can't be drawn fully. It replaces the text badge.
- The popup has an On / Off switch for every site group that matches the current site, so you can turn a group off right there. The "Hide on this tab" button is gone; the hide shortcut still works.
- Choosing an element looks like the rest of SiteMark: the panel is a ruled notebook page with wavy dividers and On / Off switches for the effects, the hint and the size tag are paper notes, and the element you point at gets a solid outline with taped corners instead of a dashed one.
- The SiteMark logo and wordmark animate again every time the popup, the settings page or a website page opens.
- New store images show the toolbar sticker, the popup switches and the notebook-style element picker.

## 1.2.3

- The Mac app now has a layered icon made with Icon Composer, so it looks right in the Dock and on the Mac App Store.
- Updated the tools SiteMark is built with (TypeScript 7, Vitest 5, Biome, Playwright). Nothing changes in how the extension works.

## 1.2.2

- Dutch: the short description is a little shorter, so the Mac App Store accepts it. Otherwise the same as 1.2.1.

## 1.2.1

- Same as 1.2.0; this version fixes the Safari publishing so the Mac App Store gets the same release.

## 1.2.0

- SiteMark is coming to Safari on the Mac, through the Mac App Store.
- Website: Help and Support are one page, "Help and support": quick links for common problems, every topic in groups, and the contact routes on taped notes at the bottom. The separate FAQ is gone because the help topics answer those questions; the Support address still works.
- Website help: new topics about site groups and settings, outline style and pulse in Marks and effects, and what to do when SiteMark reports unreadable data.
- Importing a file is nicer: drop the export file on a dashed slot, or click it to choose one. The slot reacts when you drag a file over it.
- New hand-drawn marks for what is selected: a wavy underline under the current header link, a coral outline around the current site group and help topic, a marker line under the current switch segment, and On / Off words inside the switches.
- The popup and the settings page link to the website's help: a Help link in the header and short tips under URL patterns, marks, shortcuts and diagnostics. Keyboard shortcuts are shown as key caps.
- Website: the home page now shows a shop page without and with SiteMark's marks, with a slider to compare them.
- Inline code (URL patterns, flags, paths) is now drawn as a torn strip of green washi tape, on the website and in the extension.

## 1.1.1

- Same as 1.1.0; this version fixes the store publishing so Chrome, Firefox and Edge get the same release.

## 1.1.0

- New scrapbook look: kraft paper, handwriting type and a new logo in the extension and on the website.
- New "Midnight Plum" dark theme.
- The website's install button suggests the store for your browser.
- Safari is coming in the future, not in this release.

## 1.0.0

- First release for Chrome, Edge and Firefox.
- Mark the sites you choose with ribbons, banners, outlines, stripes, watermarks, a tab-title prefix or a favicon dot.
- Pick one element on a page and mark it, with an editable CSS selector.
- Private by design: no data collected, and access is requested one site at a time.
- English and Dutch.
